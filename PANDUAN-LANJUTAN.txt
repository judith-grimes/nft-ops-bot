BAGIAN 2. CARA MEMPERBARUI APLIKASI DI PC KE VERSI TERBARU
---------------------------------------------------------------------

1. Tutup jendela hitam NFT Ops kalau sedang terbuka.

2. Buka PowerShell (klik Start, ketik "PowerShell", Enter).

3. Ketik perintah ini satu per satu (tekan Enter setelah tiap baris):

     cd "E:\OS Mints BOT\nft-ops-bot"

     git fetch origin

     git checkout stage-5-offers

     git pull

     uv sync --frozen --python 3.12

4. Jalankan lagi dengan klik dua kali file:  Start NFT Ops.bat

5. Browser akan terbuka di  http://127.0.0.1:8787/
   Biarkan jendela hitam tetap terbuka selama memakai aplikasi.

Kalau "git checkout" menolak karena ada file yang Anda ubah sendiri,
jalankan dulu:   git stash   lalu ulangi langkah 3.

BAGIAN 3. CARA MENJALANKAN SEHARI-HARI
---------------------------------------------------------------------

1. Klik dua kali "Start NFT Ops.bat" di folder E:\OS Mints BOT\nft-ops-bot
2. Masukkan password vault Anda di browser.
3. Halaman yang tersedia:
     Overview (Command center) - ringkasan, fase mint, alert, saldo
     Wallets      - impor key, buat wallet, grup, saldo
     Collections  - tambah koleksi OpenSea (slug / link / kontrak)
     Eligibility  - cek wallet mana yang eligible per fase
     Mint         - preview lalu mint dengan banyak wallet sekaligus
     Transfers    - kirim NFT, sweep dana, distribusi dana
     Contracts    - analisa kontrak + custom mint (bukan drop OpenSea)
     Offers       - Offer Manager / auto-accept offer
     Portfolio    - floor price, nilai koleksi, untung/rugi
     History      - semua transaksi
     Networks     - RPC per chain
     Settings     - batas belanja, kecepatan scan, API key OpenSea,
                    auto-lock, backup

Tombol STOP darurat menghentikan semua pengiriman transaksi.

BAGIAN 4. BACKUP DATA PRIBADI (WAJIB SEBELUM GANTI PC / UPDATE BESAR)
---------------------------------------------------------------------

Cara 1 (dianjurkan, dari aplikasi):
  Settings -> Security & backup -> Download backup
  Masukkan password. Akan terunduh file .zip (vault terenkripsi +
  database). Simpan di flashdisk / tempat aman. INGAT PASSWORD-NYA.

Cara mengembalikan (restore) backup:
  Buka PowerShell, lalu:

     cd "E:\OS Mints BOT\nft-ops-bot"

     uv run --frozen nft-ops --restore "E:\lokasi\nft-ops-backup-xxxx.zip"

  Folder data lama tidak dihapus, hanya dipindahkan ke samping.
  Lalu jalankan Start NFT Ops.bat dan buka dengan password backup itu.

Cara 2 (manual): salin seluruh folder
  E:\OS Mints BOT\nft-ops-bot\data
  ke flashdisk. Isinya sudah terenkripsi, tapi tetap simpan dengan aman.

JANGAN PERNAH:
  - mengirim private key / seed phrase ke siapa pun, termasuk ke Claude
  - meng-upload folder "data" ke GitHub
  - menyimpan private key di file CSV biasa

   field". Sudah dibuat 2 perbaikan (akun OpenSea yang terhubung ke

   -> Setelah update (Bagian 2), scan lagi wallet itu.

        "sign-in: ..."  atau  "eligibility answer: ..."  atau
        "phase check: ..."
      Salin pesan LENGKAP itu dan berikan ke Claude di sesi berikutnya.

2. Error 429 (OpenSea "too many requests") saat cek eligibility.
   Sudah diperbaiki (antrean sign-in bersama, jeda otomatis 15 dtk
   sampai 5 menit, scan berhenti sendiri kalau terus ditolak).
   -> Coba scan beberapa grup. Kalau masih sering UNKNOWN, turunkan
      kecepatan di Settings -> Eligibility scan pacing
      (misal: 1 wallet bersamaan, jeda 2 detik).
   -> Kalau baru saja kena 429, tunggu 10-15 menit sebelum scan lagi.

3. Cabang stage-5-offers BELUM digabung ke main.
   Kalau semua sudah dicoba dan aman, minta Claude:
      "merge stage-5-offers ke main"

4. Ide berikutnya yang pernah dibahas (belum dikerjakan):

Halo Claude. Saya melanjutkan proyek NFT Ops dari sesi sebelumnya.
Repo: judith-grimes/nft-ops-bot. Kerjakan di cabang stage-5-offers

Jawab saya dalam bahasa yang sederhana, langkah Windows ditulis

Ringkasan teknis:
- Aplikasi lokal Windows: Python 3.12 + uv (uv sync --frozen),
  FastAPI/uvicorn di 127.0.0.1:8787, UI vanilla JS di
  src/nft_ops/static (tema neon hijau, mode terang/gelap).
  Dijalankan lewat "Start NFT Ops.bat". Folder di PC saya:
  E:\OS Mints BOT\nft-ops-bot. Chain utama: Robinhood Chain (4663),
  banyak wallet.
- osnm-z (github.com/zunmax/osnm-z, commit b001c82) di-vendor di
  src/osnm_z. Hanya hooks.py ditambahkan, hanya logging.py dan
  submission.py yang dipatch. tests/test_vendored_integrity.py
  mengecek SHA-256. Perubahan perilaku osnm-z dilakukan lewat
  subclass, bukan mengedit file vendor (contoh:
  src/nft_ops/os_signin.py -> PacedOpenSeaClient).
- Modul utama src/nft_ops: vault (scrypt + AES-GCM), db (SQLite),
  networks/failover (RpcPool, broadcast ke semua RPC sehat),
  eligibility, mint, txengine (preview -> token sekali pakai ->
  ketik kata konfirmasi), safety (STOP + batas belanja), transfers,
  monitor, contracts/custommint, replace (speed up/cancel), backup,
  opensea_api (REST v2 + x-api-key), market (floor/portfolio),
  offer_rules + offers + seaport (auto-accept offer, Seaport 1.6).
- Pekerjaan terakhir di stage-5-offers:
  1) os_signin.py: antrean sign-in OpenSea bersama (jarak 1.2 dtk),
     jeda 15 dtk menggandakan sampai 300 dtk saat 429, retry 429
     hanya sekali, peringatan tidak lagi membanjiri konsol.
  2) eligibility.scan berhenti setelah 3 wallet berturut-turut kena
     429; sisanya UNKNOWN "OpenSea rate limited - try again later".
  3) Akun OpenSea dengan wallet Solana: data eligibility dibersihkan
     dari alamat non-EVM (drop_non_evm_wallets) dan sign-in menerima
     alamat utama akun non-EVM (check_signin_answer).
  4) Scan eligibility baru menghapus hasil lama koleksi itu;
     ada tombol "Clear results" dan info "last scan".
  Semua test lulus (79): uv run pytest -q
- Masalah terbuka: wallet 0x7b7db1358895d2C746bbf3E7A416757957B67C7F
  sebelumnya error "OpenSea returned an invalid address, integer, or
  calldata field". Perbaikan di atas belum dipastikan di OpenSea asli.
  Pesan error sekarang menyebut langkahnya (sign-in / eligibility
  answer / phase check).

Aturan keamanan saya (wajib diikuti):
- Never transmit private keys or seed phrases to external servers.
- Encrypt locally stored credentials.
- Never expose private keys in logs or UI.
- Never import private keys or seed phrases through ordinary CSV files.
- Do not create blanket NFT approvals or transfer permissions without
  explicit authorization.
- FULL AUTO must be disabled by default and require explicit activation.
- Never automatically bypass contract restrictions, CAPTCHA, anti-bot
  controls, or marketplace rate limits.
- Do not fabricate API endpoints or assume an offer can be fulfilled
  using a generic contract call.
- All execution rules must be enforced on the backend.
- Never accept multiple offers against the same NFT.

Default Offer Manager yang saya pilih: mode floor % (95%), net
proceeds 100% dari harga minimum saya, pause kalau floor turun 10%,
execution mode full tapi harus di-arm per koleksi, stablecoin (USDG)
boleh.

BAGIAN 8. ISTILAH SEDERHANA
---------------------------------------------------------------------

branch / cabang : versi kode terpisah. "merge" = menggabungkan ke main
git pull        : mengambil versi terbaru dari GitHub ke PC
vault           : brankas terenkripsi tempat private key disimpan
eligible        : wallet terdaftar di fase mint itu
UNKNOWN         : belum dapat jawaban dari OpenSea (coba lagi),
                  BUKAN berarti tidak eligible
UNVERIFIED      : wallet watch-only (tanpa key), tidak bisa dicek
429             : OpenSea bilang "terlalu banyak permintaan, pelan-pelan"
RPC             : alamat server untuk berbicara dengan blockchain
FULL AUTO       : menerima offer otomatis tanpa konfirmasi; mati secara
                  default, harus dinyalakan sendiri per koleksi
